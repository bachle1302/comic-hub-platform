## Backend Security Notes

- Helmet is enabled in `main.ts` for baseline HTTP security headers.
- Compression is enabled for HTTP responses.
- Rate limiting is enabled globally through a Redis token bucket guard.
- Default token bucket: capacity `10`, refill `1` token per second, cost `1` token per request.
- When a bucket is empty the API returns `429 Too Many Requests` with `Retry-After`.
- Bucket state is stored in Redis and route-specific buckets can be configured with `@TokenBucketRateLimit`.
- CORS is controlled by `CORS_ORIGINS`; multiple origins can be separated by commas.
- Backend auth expects `Authorization: Bearer <token>` for access and refresh flows.
- The frontend may store refresh tokens in HttpOnly cookies through Next.js Route Handlers, but the backend does not use cookie auth.
- Do not expose `JWT_ACCESS_SECRET`, `JWT_REFRESH_SECRET`, database credentials, Redis credentials, or S3 credentials.

## Known Issues / Dev Notes

- On Windows, `npx prisma generate` can fail with `EPERM` if the backend dev server or Prisma Studio is holding `query_engine-windows.dll.node`; stop those processes and run again.
- Object Storage upload requires the bucket to allow browser `PUT` with the sent `Content-Type`; public image display also requires a public bucket policy or CDN URL.
- Paid chapter image protection currently depends on the backend not returning image URLs publicly; use private/signed object URLs for stronger production protection.
- Comments support flat create/update/delete flows only. Reply nesting and realtime updates are not implemented yet.

## Deployment

When you're ready to deploy your NestJS application to production, there are some key steps you can take to ensure it runs as efficiently as possible. Check out the [deployment documentation](https://docs.nestjs.com/deployment) for more information.

If you are looking for a cloud-based platform to deploy your NestJS application, check out [Mau](https://mau.nestjs.com), our official platform for deploying NestJS applications on AWS. Mau makes deployment straightforward and fast, requiring just a few simple steps:

```bash
$ npm install -g @nestjs/mau
$ mau deploy
```

With Mau, you can deploy your application in just a few clicks, allowing you to focus on building features rather than managing infrastructure.
